r-issue: r5 / LLMがr-issueを認識・作成できない / 改善 / 高 / ✅ resolved
detail: LLM_GUIDE.md にr-issueの作成手順が記載されておらず、LLMがr-issueの存在・作成手順を認識できない。「r-issueで」と指示されてもファイルを作成できず、運用ループが機能しない。r1（ログ作成漏れ）・r2（テンプレート不準拠）と同根の問題で、LLMへの動線不足が原因。

### 原因分析
1. **LLM_GUIDE.md にr-issue手順の記載なし**: issue着手手順（§3）はあるが、r-issueについては「r1参照」「r2参照」と間接的に言及するのみ。
2. **詳細ルールが DEVELOPMENT_PROCESS.md L85-91 に埋もれている**: LLMが自発的にそこまで辿る動線がない。
3. **CLAUDE.md がテンプレートと乖離**: r1対策でissueリマインダーを直接追記したが、テンプレートの設計思想（エントリポイントはLLM_GUIDE.mdへの参照のみ）に反していた。
4. **r1→r2→r5 は同根**: いずれも「LLMに情報が届いていない」ことが原因。

### 対策
1. **LLM_GUIDE.md に§4追加**: r-issue作成のトリガー条件・作成手順を明記（全LLM共通の正本）
2. **CLAUDE.md をテンプレート準拠に戻す**: issueリマインダーを削除し、LLM_GUIDE.mdへの参照のみに
3. **GEMINI.md / CODEX.md をプロジェクトルートに配置**: テンプレートに従いエントリポイントを展開
4. **スラッシュコマンド `.claude/commands/r-issue.md` 作成**: `/project:r-issue` で構造化された作成ワークフローを呼び出し可能に（Claude固有）
