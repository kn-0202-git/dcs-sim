## 対応計画

### 1. `vite.config.ts` に `base` 追加
- GitHub Pages の URL は `https://<user>.github.io/dcs-sim/` となるため、`base: '/dcs-sim/'` を設定
- これがないとアセット（JS/CSS）のパスが解決できずに白画面になる

### 2. GitHub Actions ワークフロー作成
- `.github/workflows/deploy.yml` を作成
- main ブランチへの push をトリガーに `npm ci` → `npm run build` → GitHub Pages へデプロイ
- `actions/configure-pages` + `actions/upload-pages-artifact` + `actions/deploy-pages` を使用

### 3. GitHub リポジトリ設定
- Settings → Pages → Source を「GitHub Actions」に変更

### 4. 動作確認
- push 後に Actions タブでデプロイ成功を確認
- `https://<user>.github.io/dcs-sim/` でアプリが正常表示されることを確認
