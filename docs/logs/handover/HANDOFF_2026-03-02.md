### 設計の要点

#### データフロー（既存 → 新規追加部分）
```
draw.io SVG
  ↓ mxGraphExtractor（mxGraph XML検出・展開）     ← NEW
  ↓ mxGraphParser（XML → ParsedSVGData）          ← NEW
  ↓ mxGraphReconciler（SVGにdata-*属性注入）       ← Phase B
  ↓ 既存パイプライン（validateSvgData → buildNodes → deriveHelpers）
  ↓ SVGCanvas（変更不要）
```

統合点は `ParsedSVGData` インターフェース。新パーサーが同じ型を出力するので、バリデーター以降は変更不要。

#### バルブの扱い
draw.io ではバルブは頂点（vertex）として描かれ、2本のエッジが接続する:
```
input --pipe-1--> valve-1 --pipe-2--> tank-T1
```
valve-1 をパススルーノード（connection相当）として扱い、接続する pipe の1本に割り当てる。BFS は正しく動作する。

#### デコード方式
draw.io の content 属性は `encodeURIComponent → deflate-raw → btoa → encodeURIComponent` でエンコード。ブラウザネイティブの `DecompressionStream('deflate-raw')` で展開（外部依存なし）。テスト環境（jsdom）では DecompressionStream が無い可能性があるため、テストは非圧縮XMLを使用。
