# 要件定義書: P&ID バルブ操作シミュレーター

## 1. 背景と目的
- 背景: 既存のGrafana + SVGによるDCSシミュレーターの代替。教育・訓練用途での配管系統の理解促進。バルブ操作手順の確認・検証。
- 目的: DCS画面のような操作感でバルブ操作訓練と配管理解を促進する

## 2. ステークホルダー / 専門家役
- オーナー/ユーザー: プラントオペレーター、エンジニア、教育・訓練担当者
- プロダクトマネージャー役: 要件整理と優先度付け
- テックリード役: 技術選定と実現性評価
- UX/業務設計役: 使い勝手と運用フロー設計
- プラントオペレーター: バルブ操作の訓練と手順確認

## 3. 何を作るか（プロダクト定義）
- 化学プラントのP&IDを再現し、バルブの開閉操作によって液体がどこまで到達するかをシミュレーションするツール
- ブラウザ上で動作するSPA（サーバー不要）
- SVGベースのP&ID図描画
- BFSによる液体到達判定
- 使用技術: React + Vite + TypeScript

## 4. ゴール / 成功指標（暫定）
- バルブ操作から液流可視化まで100ms以内のレスポンス
- 訓練モードでの操作手順違反検出100%
- ブラウザのみで完結（外部サーバー不要）

## 5. スコープ
### 5.1 MVP
- バルブ操作（個別切替 + 一括操作）
- タンク状態管理（液あり/空切替）
- SVG配管図の描画と通液状態可視化
- SVGファイルインポート（アプリ上から読み込み、標準データ/取込SVGの切替）
- BFSベースの液体到達判定
- 制御パネル（バルブ、タンク）
- 凡例・到達状況サマリー

### 5.2 フェーズ2以降
- 教育機能（フェーズ/ステップ/ルール + CSV設定）
- 訓練モード / 自由モード
- CSV設定UIエディタ
- 流量表示（配管ごとの流量アニメーション）
- 操作手順記録/再生
- 複数液種対応（色分け）
- アラーム機能
- 設定保存/読込

## 6. 機能要件
### 6.1 バルブ操作機能
- 個別バルブ操作: クリックでON/OFF切替
- 一括操作: 全バルブを一括で開/閉
- 状態表示: 開=緑(#22c55e)、閉=赤(#dc2626)

### 6.2 タンク状態管理機能
- 液あり/空の切替: タンククリックで状態切替
- 液源動作: 液ありタンクは供給源
- 通過制御: 空タンクは液の通過を遮断

### 6.3 配管可視化機能
- 通液状態表示: 水色(#22d3ee) / グレー(#9ca3af, opacity 0.4)
- リアルタイム更新: 操作時即座反映
- 到達状況サマリー: 各機器への到達状況一覧

### 6.4 液流ロジック
- BFS探索による到達可能ノード判定（仕様書 Section 4.1）
- 配管通液判定（仕様書 Section 4.2）
- 液源: 入口（常時）+ 液ありタンク
- 空タンクで液の流れを遮断

### 6.5 教育機能（Phase 2）
- フェーズ/ステップ構造による訓練進行
- 安全ルールチェック（critical=阻止、warning=許可+警告）
- 条件式DSLによるステップ完了/違反判定
- CSV設定UI（直接編集、インポート/エクスポート、バリデーション）

### 6.6 SVGファイルインポート機能
- SVG読込: アプリ上からSVGファイルを選択してP&ID画面として表示
- データ抽出: `data-from` / `data-to` / `data-pipe` / `data-tank-id` からトポロジーを構築
- 表示切替: 標準データ（sample）と読込SVGをUIで切替
- 検証: 必須属性欠落・ID重複・不正参照を検知し、エラー/警告を表示

## 7. 非機能要件
- パフォーマンス: バルブ操作から描画更新まで100ms以内
- 互換性: モダンブラウザ（Chrome, Firefox, Safari, Edge最新版）
- 保守性: コンポーネント単位のテスト、TypeScript型安全
- デプロイ: 静的ファイルのみ（サーバー不要、GitHub Pages等で配信可能）
- セキュリティ: 外部入力（SVG/CSV）は検証し、危険な要素/属性混入時は読み込みを中止して安全側にフォールバックする
